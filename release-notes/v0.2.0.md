## 🎨 A brand-new interface
PalManager has been fully redesigned: a dark-first look with the Pal green, Sora / Inter / JetBrains Mono typography, bigger touch targets (44 dp minimum), bottom sheets instead of stacked dialogs, and a polished light theme. Every screen was rebuilt.

## ✨ New
- **Dashboard**: server card with address (tap to copy), players with a capacity bar and online avatars, FPS and frame time, uptime and in-game day; shortcut tiles to every tool and a bottom navigation bar (Home, Players, Map, Give).
- **Power sheet**: schedule a clean shutdown (30 s / 1 / 5 / 10 min) with a message to players, or force-stop with a **hold-to-confirm** button so a stray tap can't kill the server.
- **My servers**: each profile now shows its **live status** (online / offline / wrong password), players, FPS and latency, plus badges for the configured APIs (REST, PalDefender, SFTP).
- **Player sheet**: one bottom sheet with tabs — Team (IV and Pal Soul gauges, active skills with power and cooldown, passives), Inventory, Palbox (search + pages), Progression and Technologies.
- **Players list**: sort by level, ping or name; search by name, ID or IP; Steam / Xbox badge; color-coded ping.
- **Give item / Pal / NPC**: choose the recipient once per screen (auto-selected when only one player is online), category chips, a bottom bar with quantity presets (×1 / ×10 / ×100) or level, and one-tap giving. Full details stay one tap away behind ⓘ.
- **Guilds**: online members, a Pal preview per camp, chest fill, expedition and lab counts.
- **Live map**: selecting a player highlights and centers it instead of hiding the others; ping shown in the bottom panel.
- **Broadcast**: private messages pick their recipient from online players; new **PalDefender config reload**; restart / stop available from here too.
- **SFTP files**: clickable path breadcrumb, size and date under each entry, a selection action panel and a clipboard card for paste.
- **Logs**: level filters (Info / Warning / Error) with counts.
- **Pal Creator**: −/+ steppers for level, IVs and Pal Souls, suggestion lists for species, skills and passives.

## 🛠️ Fixes
- Saving a server profile with an empty name or host used to be silently ignored — the fields now show "Required".

## 🔁 Behavior changes
- Giving an item / Pal / NPC from the bottom bar sends it directly (the old detail dialog was the only confirmation step).
- Kicking or banning a player now closes their sheet after confirmation.
- The Pal Creator level stepper is bounded to 1–99.
