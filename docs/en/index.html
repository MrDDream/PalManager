// install

Up and running in minutes

You need a Palworld server with its REST API, and the PalDefender mod for the advanced features.

  1. Install the APK

    Download it from the latest release and open it on your phone (Android 8.0+).

  2. Enable the REST API

    In PalWorldSettings.ini: RESTAPIEnabled=True and an admin password.

  3. Add PalDefender

    Install the PalDefender mod and enable its REST API for giving, guilds and IP bans.

  4. Add your server

    Host, ports (8212 and 17993 by default), password and token, SFTP optional — then tap Verify.

Straight to your server

The app talks directly to your server's APIs. No account, no middleman service.

Encrypted secrets

Passwords and tokens are encrypted on the phone; the server's SSH key is pinned on first connection.

No tracking

No usage analytics, no ads, no tracking SDKs.
