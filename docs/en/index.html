Features

A full admin panel, not just a give-item tool.

📊

Dashboard

Server info, online players, FPS, Palworld/PalDefender versions, save, restart/shutdown.

👥

Connected players

Real-time list, kick/ban, private message, per-player inventory/team/progression/technologies. Team Pals are tappable (IV, Pal Soul, skills, passives).

🛡️

Guilds

Search by guild or member name, all base locations pinned on the map, per-camp Pal roster with detail view, chest, expeditions and lab research.

🎁

Give item / Give Pal

Search by name or image in a bundled catalog (items, Pals, NPCs, technologies), filters by category/element/rarity/work suitability.

🗺️

Live map

Player positions on the Palpagos Islands map.

🚫

Bans

Player and IP bans.

📣

Broadcast & maintenance

Broadcast, alerts, messages, danger zone (reload config, delete base).

🐞

Debug logging

Optional network request log written to a folder you choose, to help diagnose connectivity issues.

SFTP toolkit (optional)

Add SSH/SFTP credentials to a server profile to unlock a few extras.

📜

Logs

PalDefender/UE4SS log viewer with search and colored severity.

🗂️

SFTP file manager

Browse/upload (file or whole folder)/download/rename/copy/cut/paste/delete, with trust-on-first-use host key pinning.

✨

Pal Creator

Build a PalDefender Pal Template (species, gender, level, shiny/alpha, IVs, Pal Souls, skills) from a form and save it straight to the server's template folder.

✅

Verify

One tap on the Add/Edit server screen checks the Palworld API, PalDefender API, and SFTP are all reachable with what you just typed in.

Preview

Real screenshots of the app (server/players blurred for privacy).

Server requirements

  • A Palworld server with the official REST API enabled (RESTAPIEnabled=True in PalWorldSettings.ini).
  • The PalDefender mod installed with its REST API enabled, for features the official API doesn't cover (give item/Pal, techs, guilds, IP bans...).

Tech stack

Kotlin Jetpack Compose Material 3 Hilt Room Retrofit / OkHttp Coil Navigation Compose
