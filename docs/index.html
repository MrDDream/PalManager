Installation

  1. Télécharge l'APK depuis la dernière version et installe-le (Android 8.0 ou plus ; autorise les sources inconnues si demandé).
  2. Ajoute un serveur : hôte, port de l'API REST Palworld (8212 par défaut) et mot de passe admin, port de l'API PalDefender (17993 par défaut) et token, et en option les identifiants SSH/SFTP.
  3. Touche Vérifier pour contrôler que tout répond, puis enregistre.

Prérequis serveur

  • Un serveur Palworld avec l'API REST officielle activée (RESTAPIEnabled=True dans PalWorldSettings.ini).
  • Le mod PalDefender avec son API REST activée, pour ce que l'API officielle ne couvre pas (don d'items et de Pals, technologies, guildes, bannissements IP…).
  • En option : un accès SSH/SFTP à la machine du serveur, pour la boîte à outils SFTP.
