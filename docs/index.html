PalManager

Pilote ton serveur dédié Palworld depuis ton téléphone — joueurs, inventaires, Pals, guildes, bannissements et plus, via l'API officielle et PalDefender.

⚠️ Projet non-officiel, sans lien avec Pocketpair
⬇ Télécharger l'APK Voir le code sur GitHub

Fonctionnalités

Un panel d'admin complet, pas juste un give-item.

📊

Dashboard

Infos serveur, joueurs en ligne, FPS, versions Palworld/PalDefender, sauvegarde, redémarrage/arrêt.

👥

Joueurs connectés

Liste en temps réel, kick/ban, message privé, inventaire/équipe/progression/technologies par joueur.

🎁

Give item / Give Pal

Recherche par nom ou image dans un catalogue embarqué (items, Pals, PNJ, technologies), filtres par catégorie/élément/rareté/métier.

🗺️

Carte en direct

Position des joueurs sur la carte des Îles Palpagos.

🛡️

Guildes & bannissements

Gestion des guildes, bannissements joueurs et IP.

📣

Diffusion & maintenance

Broadcast, alertes, messages, zone danger (reload config, suppression de base).

Aperçu

Captures d'écran réelles de l'application (serveur/joueurs floutés pour la confidentialité).

Prérequis serveur

  • Un serveur Palworld avec l'API REST officielle activée (RESTAPIEnabled=True dans PalWorldSettings.ini).
  • Le mod PalDefender installé et son API REST activée, pour les fonctionnalités que l'API officielle ne couvre pas (give item/Pal, techs, guildes, bans IP...).

Stack technique

Kotlin Jetpack Compose Material 3 Hilt Room Retrofit / OkHttp Coil Navigation Compose
